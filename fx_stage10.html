🎀 ルナと学ぶ20回

各回のピンクのボタンから教材へ進めるよ。第1回から順番に練習してね。

第1回 チャート全体を見る

まず大きな値動き、トレンドとレンジ、重要な価格帯を把握する。

📖 第1回「チャート全体を見る」を開く →

第2回 複数時間足を見る

4時間足で方向を確認し、5分足でタイミングを探す。時間足が逆向きなら慎重に。

📖 第2回「複数時間足を見る」を開く →

第3回 トレンドを判断する

高値と安値の切り上げ・切り下げを確認。MAだけでなく価格構造を見る。

📖 第3回「トレンドを判断する」を開く →

第4回 高値・安値を見る

直近の山と谷、前回高値・安値の更新を見てトレンドの継続や転換を考える。

📖 第4回「高値・安値を見る」を開く →

第5回 20MAを見る

20期間移動平均線は比較的短い流れを表す。価格との位置と傾きを確認する。

📖 第5回「20MAを見る」を開く →

第6回 200MAを見る

200期間移動平均線はより長い流れの目安。上位足と合わせて大局を確認する。

📖 第6回「200MAを見る」を開く →

第7回 MAの方向を見る

20MAと200MAが同じ方向か、横ばいか、逆向きかを比較する。

📖 第7回「MAの方向を見る」を開く →

第8回 RSIを見る

RSI(14)は値動きの勢いを見る補助指標。50付近や55/45などの基準を条件に照らす。

📖 第8回「RSIを見る」を開く →

第9回 ADXを見る

ADX(14)はトレンドの強さの目安で、方向そのものは示さない。25は参考基準で万能ではない。

📖 第9回「ADXを見る」を開く →

第10回 サポート・レジスタンスを見る

何度も止まった価格帯を線ではなく幅のあるゾーンとして確認する。

📖 第10回「サポート・レジスタンスを見る」を開く →

第11回 押し目・戻りを探す

大きな方向に沿って一時的に逆行した位置を探す。反転確認なしの飛び乗りは避ける。

📖 第11回「押し目・戻りを探す」を開く →

第12回 ブレイクを確認する

重要な高値・安値の突破と終値、出来高等の補助情報を確認。突破直後の追随は慎重に。

📖 第12回「ブレイクを確認する」を開く →

第13回 ダマシを警戒する

抜けた直後に元のレンジへ戻ることがある。足の確定や再テストも見る。

📖 第13回「ダマシを警戒する」を開く →

第14回 経済指標を確認する

重要発表前後は急変・スプレッド拡大に注意。カレンダーを必ず確認する。

📖 第14回「経済指標を確認する」を開く →

第15回 買い・売り・見送りを判断する

複数条件を照合し、条件が揃わなければ見送りを選ぶ。取引しない判断も正解。

📖 第15回「買い・売り・見送りを判断する」を開く →

第16回 エントリーする

事前に決めた条件が成立した場合だけ注文する。成行・指値の違いと滑りを理解する。

📖 第16回「エントリーする」を開く →

第17回 損切り・利確を決める

想定が崩れる価格に損切りを置き、利確は次の価格帯と損益比から決める。逆指値も約定価格は保証されない。

📖 第17回「損切り・利確を決める」を開く →

第18回 ロットを決める

許容損失額÷（損切り幅×1pipあたりの損益額）で数量を考える。通貨ペアと口座通貨で換算が必要。

📖 第18回「ロットを決める」を開く →

第19回 トレード後に記録・検証する

エントリー理由、決済理由、損益、ルール遵守を記録し、勝敗だけで評価しない。

📖 第19回「トレード後に記録・検証する」を開く →

全体→上位足→価格構造→MA→RSI/ADX→指標→リスク→判断→記録を通しで行う。
